# Реконструкция сайта ООО "МИХЕЕВ"

## Выполненные работы

### 1. Улучшение современного дизайна

#### Создан единый CSS-файл (modern.css)
- **CSS переменные** для удобного управления цветами и стилями
- **Современная цветовая палитра**:
  - Основной цвет: #A33D49 (бордовый)
  - Вторичный цвет: #007FA0 (синий)
  - Акцентный цвет: #41B3D1 (голубой)
- **Адаптивный дизайн** с медиа-запросами для мобильных устройств
- **Плавные анимации** и переходы
- **Тени и скругления** для современного вида

#### Улучшения UI/UX
- Sticky navigation (фиксированное меню)
- Выпадающие меню с анимацией
- Интерактивные карточки продуктов и категорий
- Плавная прокрутка к якорям
- Анимация появления при скролле

### 2. Создание недостающих страниц в новом стиле

#### modern_contacts.html - Страница контактов
- Контактная информация с иконками
- Форма обратной связи с валидацией
- Интерактивная карта (Google Maps embed)
- Карточки с адресом, телефоном, email, режимом работы

#### modern_partners.html - Страница партнёрам
- Преимущества сотрудничества
- Условия для разных типов партнёров
- Список необходимых документов
- Пошаговая инструкция становления партнёром
- Призыв к действию с контактами отдела продаж

### 3. Рефакторинг и оптимизация кода

#### modern.css - Оптимизированные стили
- Модульная структура с комментариями
- Переменные CSS для легкой кастомизации
- Утилитарные классы (.text-center, .mt-20, .mb-40 и др.)
- Оптимизированные медиа-запросы
- BEM-подобная методология именования

#### modern.js - Современный JavaScript
- ES6+ синтаксис
- Intersection Observer для анимаций
- Валидация форм
- Popup для просмотра изображений
- Автоматическое определение активной навигации
- Обработка мобильного меню

#### Обновлённый modern_index.html
- Исправлены ссылки на другие страницы
- Семантическая HTML5 разметка
- Доступность (ARIA-ready структура)
- Оптимизированная загрузка ресурсов
